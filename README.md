# 🎓 Student Academic Tracker

A full-stack web application built to manage and track student academic performance efficiently.  
The system provides a secure Student Portal and an advanced Admin Dashboard for complete academic management.

---

## 📌 Project Overview

Student Academic Tracker is designed to simplify academic record management.  
It allows administrators to manage students, semesters, and courses, while students can securely view their academic performance and download reports.

This project demonstrates full-stack development using modern technologies with authentication, analytics, and dynamic UI.

---

### 👨‍🎓 Student Portal
- Secure login using Roll Number + Date of Birth
- View semester-wise course records
- Automatic CGPA calculation
- Interactive CGPA performance chart
- Download academic report as PDF
- Clean and responsive UI

---

### 👨‍💼 Admin Dashboard
- Secure Admin Login (JWT Authentication)
- Add / Edit / Delete Students
- Add / Edit / Delete Semesters
- Add / Edit / Delete Courses
- Dynamic grade updates
- Department filtering
- Batch filtering
- Real-time CGPA display
- Student analytics dashboard

---

## 📊 Core Functionalities

- Full CRUD operations (Students, Semesters, Courses)
- Nested MongoDB document structure
- Dynamic CGPA calculation logic
- Role-based access (Admin / Student)
- Token-based authentication
- RESTful API integration
- PDF report generation
- Responsive UI using Tailwind CSS

---

## 🛠️ Tech Stack

### 🔹 Frontend
- React
- TypeScript
- Tailwind CSS
- Lucide Icons
- Chart Visualization (CGPA Graph)

### 🔹 Backend
- Node.js
- Express.js
- MongoDB (Mongoose)
- JWT Authentication
- REST API Architecture
